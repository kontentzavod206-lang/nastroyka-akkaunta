# Настройка аккаунта

Полный переносимый промпт для настройки нового ПК и нового аккаунта Codex: папки, правила агента, инструменты разработки, библиотеки и подключения.

## Как использовать

1. Откройте [SETUP-PROMPT.md](SETUP-PROMPT.md).
2. Скопируйте весь текст после разделителя в новый чат Codex на нужном ПК.
3. Агент проверит среду и выполнит доступную настройку. Вход в аккаунты и выдача разрешений выполняются отдельно на новом ПК.
4. После настройки получите отчёт о фактических версиях, проверках и оставшихся действиях.

По умолчанию рабочая папка — `D:\AI\Codex`; если диска D нет, агент предложит другой путь.

Включены Python, Node.js LTS, npm, Git, VS Code, React, FastAPI, Streamlit и pandas. Плагины проверяются по доступности; настройка аккаунтов не переносится автоматически.

Агенты для сложных проектов запускаются только после явного согласия пользователя.

Репозиторий содержит инструкции. Его открытие или клонирование само по себе не устанавливает программы. Пароли и токены здесь не хранятся.
